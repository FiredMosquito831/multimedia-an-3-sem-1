# Multimedia – Year 3, Semester 1 (2026-2027)

Course and seminar materials for **Multimedia** (Informatică economică, engleză, anul 3, semestrul 1).

## Structure

- `Cursuri/` – lecture slides, one folder per week
- `Seminarii/` – seminar slides and exercises, one folder per topic
- `Cheatsheets si sinteze/` – notes and summaries
- `Examen/` – exam material

The repository is private because the lecture and exercise files belong to the course staff.
